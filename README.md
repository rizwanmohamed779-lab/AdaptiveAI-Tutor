# AdaptiveAI Tutor – Personalised AI Learning Agent

## 💡 Project Overview

AdaptiveAI Tutor is a personalised AI learning agent designed to help students learn AI and related technologies according to their individual knowledge level.

The system assesses the learner's AI/ML knowledge, detects their level as Beginner, Intermediate, or Advanced, and provides a personalised learning experience.

## ✨ Key Features

- Student profile and learning goal selection
- AI/ML skill assessment
- Automatic level detection
- Personalised learning roadmap
- AI-powered tutor using Groq
- Adaptive quizzes
- Performance-based recommendations
- Progress dashboard

## 🛠️ Technologies Used

- Python
- Streamlit
- Groq API
- OpenAI GPT-OSS-20B
- python-dotenv
